# ContactHeat

Sixty days of contact with one person, a square per day, so silence shows as a run of empty cells.

- Calls are `ink`, emails `ink-faint`, meetings `meeting`, notes you log `select`. The key sits above the cells.
- The summary line under it says what the gaps mean against the deal's cadence: "34 days quiet. Discovery allows 10." Bold goes `late` only when the cadence is broken.
- Consumer provides `cells` (oldest first, `null` for no contact) and the `summary`.
