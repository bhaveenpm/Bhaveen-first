# EmptyState

What a pane says when it has nothing to show: why, and the one or two things that would fill it.

- First run explains where the queue's items come from, using the reason marks, and offers the first actions: "Import Google contacts", "Connect calendar".
- A cleared queue says it is done and how many items are with the other side. No celebration.
- Consumer provides `title`, a sentence as children, optional `rules` and `actions`.
