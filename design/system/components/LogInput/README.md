# LogInput

The one field for writing down what was said: a call, a note, or a promise.

- Place it at the top of the relationship's side column. `L` focuses it.
- Enter logs. Logging resets that person's silence clock and the toast says so.
- Placeholder names what to write, specific to the person when it is their first: "First call with Inès…".
- Consumer provides `onLog(text)`.
