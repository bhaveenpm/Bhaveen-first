# PromiseItem

Something someone here said they would do, with the day they said it.

- The due date reads in relative days ("3 days ago", "in 7 days"); `late` colours it when it has passed and the promise is still open.
- Ticking it marks the promise kept: the box fills `renewal` and the words strike through. It never disappears; kept promises are the record.
- Consumer provides `what`, `due`, `late`, `done` and `onToggle`.
