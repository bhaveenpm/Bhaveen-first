# ReasonMark

The shape that says why an item is on your day: a filled dot for a promise you made, a ring for a reply you are waiting on, a gold diamond for a meeting today, a fading bar for a relationship going quiet, a green triangle for a renewal ahead.

- Use it at the start of every queue row, in the detail eyebrow, and in the first-run rules. It is Halden's signature; nothing else in the product is drawn this way.
- The shape carries the meaning, so the five stay distinguishable without colour. Lateness is the only thing colour adds: `late` turns a promise dot or a reply ring `late`.
- Never add a sixth shape for decoration. A new reason earns a new shape only when the engine can produce it.
- Consumer provides `kind`, and `late` when the item is past due. When a visible word sits beside the mark, pass `label=""` so screen readers do not hear it twice.
