# Toast

A one-line confirmation after an action, with Undo when the action can be undone.

- Repeat the button's verb in the past tense and name who it touched: "Marked sent · Nadia Okonjo".
- Undo is offered for five seconds; `U` does the same thing.
- Inverted (`ink` ground, `ground` text) so it reads over either pane.
