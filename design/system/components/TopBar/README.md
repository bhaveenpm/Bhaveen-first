# TopBar

The desk's top edge: the wordmark, the screens, where you are, and on the right whatever scopes or counts this screen needs, ending with your initials.

- `nav` lists the screens in a fixed order: Today, Deals, People. The current one is `ink` at 600 with a `select` underline. Today carries a count of late and due items in `late`; no other screen has a count.
- `where` names the context in `ink-muted` after the nav: "Thursday 27 Aug", "Kestrel Instruments · Field measurement". Leave it out when the nav already says it.
- Right side, in this order when present: a Segmented scope, mono counts with late first, then the `me` initials button, which opens the account menu.
