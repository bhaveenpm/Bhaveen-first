# WhyBlock

The reason an action is on your day, in one sentence: the fact that matters in bold, the context after it.

- Lead with the fact ("Due 3 days ago.", "Sent 9 days ago, no reply."), then the context in plain words ("You said Monday, on the call."). Both are sentences.
- `also` lists promises folded into this action, so one meeting never becomes three rows.
- `late` colours the bold fact `late`. Nothing else in the block changes.
